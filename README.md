# [▶ Открыть приложение «Пульс канала»](https://sonicgames1807-star.github.io/site-youtube-channel-puls/)

Вы сейчас смотрите страницу файлов на GitHub. Само приложение открывается по большой ссылке выше. На телефоне откройте ссылку прямо в Chrome или Safari.

## Файлы сайта

Готовый статический сайт. Для публикации не нужны Node.js, сборка или сервер. В полном архиве файлы сайта лежат в корне, а папка `dist` содержит копию исходной сборки. В архиве нет секретного ключа Google. OAuth Client ID в `app.js` является публичным идентификатором веб-приложения.

## Как опубликовать

1. Распакуйте **содержимое** архива в корень репозитория: `index.html`, `app.js`, `styles.css`, `.nojekyll` и `README.md` должны лежать рядом. Ваш репозиторий уже создан и сайт опубликован.
2. Загрузите файлы в ветку `main`.
3. Откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
4. Дождитесь адреса сайта вида `https://USERNAME.github.io/REPOSITORY/`.

## Чтобы работал вход через Google

Для этого сайта в Google OAuth-клиенте **Puls Kanala website** уже указан источник:

`https://sonicgames1807-star.github.io`

Если позже используете собственный домен, его точный HTTPS-адрес потребуется добавить в [Google Auth Platform → Clients](https://console.cloud.google.com/auth/clients) как отдельный источник.

На телефоне открывайте сайт прямо в Chrome или Safari. Встроенные браузеры Telegram, GitHub и других приложений могут блокироваться политикой Google OAuth. Если ошибка остаётся, откройте на странице Google «Сведения об ошибке» и проверьте точный код: `origin_mismatch` означает, что источник для текущего домена отсутствует; `disallowed_useragent` означает, что ссылка открыта во встроенном браузере.

Приложение Google пока в режиме **Testing**: войти могут только аккаунты, добавленные в список тестовых пользователей Google Auth Platform. Для свободного входа всех посетителей потребуется публикация и проверка OAuth-приложения в Google.

## Как устроены данные

- После нажатия «Войти через Google» сайт просит только доступ на чтение YouTube-канала и YouTube Analytics.
- Токен доступа хранится только в памяти открытой вкладки и теряется после её закрытия или перезагрузки. Он не включён в архив и не отправляется на сервер сайта.
- Публичный счётчик подписчиков может округляться YouTube. Подробные отчёты YouTube Analytics обычно поступают с задержкой 48–72 часа.
- До подключения сайт явно показывает демо-данные.

## Особенности панели

- У каждой карточки свой период: 7, 28, 90, 365 дней или всё время. Переключение одной карточки не меняет остальные.
- «Лаборатория роста» показывает три сигнала: темп просмотров за последние 7 дней относительно предыдущих 7, число новых подписчиков на 1000 просмотров и долю просмотров самого популярного видео за 28 дней.
- Ползунок сценария рассчитывает число подписчиков через 28 дней при выбранном изменении просмотров. Расчёт предполагает, что соотношение просмотров и новых подписчиков сохранится, а число отписок останется на уровне последних 28 дней. Это модель, а не обещание результата.
- Можно задать личную цель по подписчикам. Она сохраняется только в браузере на текущем устройстве, отдельно для каждого канала. Дата достижения оценивается по чистому приросту за последние 28 дней.
